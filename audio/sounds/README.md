# Звуки приключения

Основная подборка: 30 эффектов BigSoundBank / LaSonotheque длительностью 3–5 секунд и 8 длинных атмосферных петель SpritePilot. Для полевых записей выбраны содержательные фрагменты: двери, цепи, шаги, копыта, нежить, колокола, гром, вода, монеты. Без замедления, повторения коротких семплов и добавления тишины. Выровнен пик громкости и добавлены короткие плавные края.

BigSoundBank: https://bigsoundbank.com. CC0 / эквивалент общественного достояния; авторы и исходные записи доступны по sourceUrl каждой записи в manifest.json. Лицензия указана на каждой странице sourceUrl. Поля originalDurationSeconds и excerptStartSeconds фиксируют происхождение каждого фрагмента; durationSeconds и sha256 проверяют опубликованный файл.

SpritePilot: https://spritepilot.com/free-game-assets/sound-effects. Лицензия CC0 1.0 приложена в LICENSE.txt.

Все записи имеют тип sound. Они добавляются в существующую IndexedDB-библиотеку при открытии вкладки «Звуки». Новые эффекты имеют новые стабильные идентификаторы, поэтому появятся и у тех, кто уже импортировал первую подборку. Пользовательская музыка, имена и папки сохраняются.

70 прежних коротких эффектов остаются в хранилище без изменения аудио и доступны через папку «Архив · короткие эффекты». В основном списке они скрыты. Длинные атмосферы сохранены; повтор включается вручную. Длительность новых эффектов указана в списке.
