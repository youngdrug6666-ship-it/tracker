Руководство по трекеру боя D&D 5e

  • ➕ Добавление участников: Нажмите Бестиарий — откроется панель со списком монстров. Используйте фильтры по папкам и CR. « Добавить» помещает монстра в бой. Героев можно добавить через Меню → Новый герой или импортировать JSON.
  • 🎲 Инициатива: В карточке есть поле «Инициатива» и кнопка d20. Кнопка Инициатива монстрам бросает инициативу всем монстрам. Сортировать по иниц упорядочивает ходы.
  • ❤️ Хиты и урон: Поле ввода урона/лечения и кнопки: ⚔️ — нанести урон, ½ / ¼ / ×2 — модификаторы, 💚 — лечение. У монстров есть — перебросить ХП по формуле.
  • 📋 Состояния: Нажмите «📋 Состояния» в карточке, чтобы открыть панель. Выбранные состояния отображаются цветными бейджами. Кнопка «❌ Сбросить всё» убирает все состояния.
  • 🔮 Заклинания: У заклинателей отображаются ячейки (кнопки +/-). В детальном окне (через в карточке) показан полный список заклинаний. Клик по названию открывает описание.
  • 💾 Кампании (сессии): В Меню есть выбор кампании, кнопки Переим., Сессия, Удалить сессию. Состояние боя сохраняется автоматически.
  • ⌨️ Горячие клавиши: Стрелки ← / → — предыдущий/следующий ход. Esc закрывает модальные окна.
  • 📱 Интерфейс: Бестиарий открывается слева. Карточки можно перетаскивать для ручной сортировки.
