Руководство по трекеру боя D&D 5e

  • ➕ Добавление участников: Нажмите Бестиарий — откроется панель со списком монстров. Используйте фильтры по папкам (иконки) и CR. Кнопка « Добавить» помещает существо в бой. Героев добавляйте через Меню → Новый герой или импорт JSON.
  • 🎲 Инициатива: В карточке есть поле «Инициатива» и кнопка d20 (бросок 1d20 + бонус). Кнопка Инициатива монстрам бросает инициативу всем монстрам. Сортировать по иниц упорядочивает очередь ходов.
  • ❤️ Хиты и урон: Введите число в поле «урон», затем используйте кнопки: ⚔️ — нанести урон, ½ / ¼ / ×2 — модификаторы, 💚 — лечение. У монстров есть — перебросить ХП по формуле.
  • 📋 Состояния: Нажмите «📋 Состояния» в карточке, чтобы открыть панель. Выбранные состояния отображаются цветными бейджами. Чтобы снять состояние, нажмите на его бейдж или снова выберите в панели. Кнопка «❌ Сбросить всё» убирает все состояния сразу.
  • 🔮 Заклинания: У заклинателей отображаются ячейки (кнопки +/-). В детальном окне (через в карточке) показан полный список заклинаний, сгруппированный по уровням. Каждое заклинание подсвечивается цветом своей школы (Ограждение, Воплощение, Некромантия и т.д.). Клик по названию открывает полное описание.
  • 💾 Кампании (сессии): В Меню есть выпадающий список кампаний, а также кнопки: Переим., Сессия, Удалить сессию. Состояние боя автоматически сохраняется в браузере. Сброс сессий удаляет все данные и начинает новую чистую кампанию.
  • ⌨️ Горячие клавиши: Стрелки ← / → — предыдущий/следующий ход. Esc закрывает модальные окна.
