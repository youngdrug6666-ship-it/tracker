# Полный экспорт данных Foundry для трекера

1. Откройте мир Foundry от имени мастера, включите нужный модуль со сборниками.
2. Создайте новый макрос. Тип — **Script / Скрипт**.
3. Вставьте весь код из `foundry-export-tracker.js`, сохраните и запустите.
4. В окне выберите сборники **правил 2014 года**: монстры, заклинания, классы, подклассы, классовые особенности. Сборники `laaru-dnd5-hw` выбраны по умолчанию, остальные можно выбрать вручную.
5. Нажмите **Скачать JSON** и дождитесь окончания. Если браузер спросит разрешение на несколько скачиваний, разрешите его. При большом объёме будет несколько частей до 24 МБ.
6. Пришлите полученный файл или все части в чат. Не используйте кнопку импорта персонажа на сайте: это другой формат.

Макрос читает сборники и скачивает файлы локально. Документы мира, персонажи игроков и настройки мира не экспортируются. Исходные документы не изменяются.

Сохраняются исходные `system`, `activities`, старое `activation`, компоненты, материалы, дальность, длительность, использование и восстановление ресурсов, источник/редакция, классы/подклассы с `advancement`, все вложенные предметы монстров, UUID, описания, эффекты и флаги. Пути изображений сохраняются, сами изображения не скачиваются.

Это убирает потери при экспорте, но не исправляет неправильную настройку самого сборника. Если у способности отсутствует тип действия в исходных данных, её нужно сопоставить с проверенным источником. Принадлежность заклинания подклассу может храниться в классовых особенностях/advancement, а не в самом заклинании; поэтому нужны все перечисленные сборники. Общий выбор заклинаний (например, «Магические тайны») не равен специальному списку подкласса.

В JSON есть версия системы, перечень выбранных сборников, статистика покрытия и ошибки чтения. Неудачно прочитанные сборники также перечисляются в уведомлении Foundry.
